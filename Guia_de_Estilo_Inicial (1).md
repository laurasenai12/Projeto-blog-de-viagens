Tipografia

Textos — Raleway - Regular - 14 px
A Lusitana foi escolhida para os textos e informações da interface por apresentar uma aparência mais discreta.

Fonte complementar — Merriweather - Regular - 24 px
A Luxurious Roman é utilizada como fonte complementar em elementos específicos da interface.

Aplicação no Projeto
As cores e tipografias são aplicadas na página inicial do Rota Livre de forma a criar uma identidade visual consistente. A cor predominante ocupa as áreas maiores da interface, enquanto o azul claro é utilizado como base para o conteúdo. O azul escuro é reservado para elementos de destaque e ações do usuário. A combinação das fontes cria uma hierarquia visual, diferenciando títulos, informações e elementos complementares.
