# Rota Livre 


## Descrição Resumida do Projeto
O **Rota Livre** é um blog de viagens desenvolvido para ajudar usuários a planejarem passeios pelo Brasil. O site reúne ofertas, sugestões de roteiros práticos, dicas de hospedagens, passagens, atrações turísticas e aluguel de carros, tudo organizado de forma intuitiva por destino.

## Estrutura Analítica do Projeto (EAP) e Cronograma

Módulo 1: Documentação e Escopo - Definição do escopo do produto, público-alvo, wireframes, mapa do site e README
Módulo 1: EAP e Guia de Estilo - Aplicação da Regra 60-30-10, definição da paleta de cores, tipografia e peer review
Módulo 2: Construção das páginas `index.html`, `roteiros.html` e `hospedagens.html`
Módulo 2: Responsividade e UI/UX - Ajuste do layout responsivo com CSS Flexbox/Grid para celular e desktop
Módulo 3: Banco de Dados & Back-End - Cadastro de roteiros, hospedagens e armazenamento do formulário de contato - Não Conclúido
