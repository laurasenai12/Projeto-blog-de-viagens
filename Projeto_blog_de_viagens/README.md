# Rota Livre - Blog de Viagens

## Descrição do Projeto

O Rota Livre é um blog de viagens criado para ajudar usuários a planejarem passeios pelo Brasil. O site reúne sugestões de roteiros, dicas de hospedagens e informações sobre atrações turísticas. Os primeiros destinos apresentados serão Rio de Janeiro, Gramado e Canela e Porto de Galinhas.

O projeto possui três páginas principais: Home, Roteiros e Hospedagens e Contato. A navegação será simples e responsiva, permitindo que o visitante encontre informações pelo computador ou celular.

## Estrutura Analítica do Projeto (Resumo das entregas)

- Documento de escopo do produto.
- Mapa do site com o fluxo de navegação.

### Módulo 2 - Front-End

- Desenvolvimento da página Home.

- Desenvolvimento da página Hospedagens e Contato.

### Módulo 3 - Banco de Dados e Back-End

- Planejamento das informações de roteiros, hospedagens e contatos.
